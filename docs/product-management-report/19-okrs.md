## OKR Philosophy at DramaSnap

OKRs at DramaSnap follow three principles:
1. **Moonshots over sandbagging:** Key results should be ambitious — 70% achievement is success. If we hit 100% consistently, we're not setting ambitious enough targets.
2. **Outcomes over outputs:** Key results measure user behavior and business outcomes, not features shipped or tasks completed.
3. **Aligned but autonomous:** Company OKRs set direction; team OKRs define the path. Teams choose *how* to achieve company KRs — they are not prescribed a feature list.

**Confidence scores:** Each key result carries a confidence score (0–100%) reflecting the team's belief in achieving the target. 50% = aggressive. 70% = achievable. 90% = too easy.

## Weekly OKR Rhythm

| Cadence | Activity | Participants | Output |
|---|---|---|---|
| **Weekly (Monday)** | OKR check-in: update key result confidence scores | Team leads | Updated Notion OKR tracker |
| **Weekly (Wednesday)** | Metrics review: key metric dashboard review | All teams | Metric anomalies flagged, experiments updated |
| **Bi-weekly** | Experiment review board: review running A/B tests | PM + Data | Ship/extend/kill decisions |
| **Monthly (1st week)** | OKR health check: review progress, adjust plans | Leadership + Team leads | Blocker identification, resource reallocation |
| **End of Quarter** | OKR retrospective: score key results, capture learnings | All teams | OKR score sheet, learnings documented for Q3 planning |

### Weekly Check-in Format

Each team lead submits a brief weekly OKR update following this template:

```
Team: [Team Name]
Week ending: [Date]

KR [X.X]: [Key Result description]
  Current: [metric value]
  Target: [target value]
  Progress: [% of target achieved]
  Confidence: [0-100%]
  Blockers: [if any]
  This week's focus: [key action]
```

### OKR Scoring (End of Quarter)

| Score | Interpretation |
|---|---|
| 0.0 – 0.3 | We failed to make meaningful progress. What went wrong? |
| 0.4 – 0.6 | Progress made but fell short. Evaluate root cause. |
| 0.7 – 0.9 | Strong execution. This is the target range. |
| 1.0 | Either we achieved a moonshot (celebrate) or we set the target too low (recalibrate). |

*OKR scores are not performance reviews. A 0.5 on an aggressive KR may reflect better execution than a 1.0 on a sandbagged one.*
