# DramaSnap - Content Guidelines & AI Generation Standards

## Content Philosophy

DramaSnap delivers emotionally engaging, binge-worthy short-form drama that respects our audience's time and intelligence. Every episode must advance the story, deepen character development, or reveal crucial information.

## Content Structure

### Movie Format

**Total Duration:** 60-120 minutes
**Episode Length:** 60 seconds each
**Episodes per Movie:** 60-120 episodes
**Optimal Length:** 100 episodes (~100 minutes)

### Episode Structure (60 seconds)

```
0-5 seconds:   Hook/Recap (if needed)
5-45 seconds:  Core story content
45-55 seconds: Emotional beat or revelation
55-60 seconds: Cliffhanger/Setup for next episode
```

**Key Principles:**
- Every episode must end with a reason to watch the next one
- No filler content
- Clear visual storytelling (vertical format)
- Dialogue-driven but visually dynamic
- Emotional resonance in every episode

## Genre Guidelines

## AI Generation Pipeline

### Phase 1: Concept Development

**Input Parameters:**
- Genre (primary and secondary)
- Target length (number of episodes)
- Tone (light, medium, dark)
- Themes (betrayal, redemption, love, etc.)
- Setting (contemporary, historical, fantasy)

**AI Prompt Structure:**
```
Generate a compelling [GENRE] story with [SECONDARY_GENRE] elements.

Requirements:
- Length: [NUM_EPISODES] episodes of 60 seconds each
- Tone: [TONE]
- Themes: [THEMES]
- Setting: [SETTING]
- Target audience: 18-35, enjoys serialized drama
- Vertical video format (9:16)
- Each episode must end with a hook

Create:
1. Logline (one sentence summary)
2. Story premise (2-3 paragraphs)
3. Main characters (3-5 characters with descriptions)
4. Three-act structure outline
5. Major plot points and twists
```

**Output:**
- Approved story outline
- Character profiles
- Episode breakdown (major beats)

### Phase 2: Script Generation

**Episode Script Template:**
```
EPISODE [NUMBER]: [TITLE]

SETTING: [Description]
TIME: [Day/Night, Season]
CHARACTERS: [Present in this episode]

[DIALOGUE AND ACTION]

CHARACTER A
(emotion)
Dialogue line...

[VISUAL DESCRIPTION]
Camera focuses on object/character reaction

CHARACTER B
(emotion)
Response dialogue...

[CLIFFHANGER/HOOK]
Description of ending moment

---
NEXT EPISODE HOOK: [Teaser for next episode]
```

**AI Script Prompts:**
```
Context: [Story outline, character profiles, previous episodes]

Generate Episode [NUMBER]:
- Advance plot: [Specific plot point to cover]
- Character development: [Which character(s) to focus on]
- Emotional beat: [Target emotion]
- Cliffhanger: [Type: revelation, danger, decision, etc.]

Constraints:
- Dialogue: Natural, character-consistent
- Length: ~150-200 words of dialogue + action
- Pacing: Quick, engaging
- Visual: Describe key shots for vertical format
- End: Strong hook for next episode
```

**Quality Checks:**
- Character voice consistency
- Plot logic
- Pacing (not too slow or rushed)
- Emotional impact
- Cliffhanger effectiveness
- Dialogue naturalness

### Phase 3: Visual Generation

**Storyboard Creation:**
```
For each episode:
1. Identify key shots (5-8 shots per episode)
2. Generate shot descriptions
3. Maintain visual consistency (characters, locations)
4. Optimize for vertical format (9:16)
```

**Shot Types for Vertical Format:**
- Close-ups (faces, emotions)
- Medium shots (conversation, interaction)
- Creative angles (dutch tilt, low angle, high angle)
- Movement (slow pan, zoom, rack focus)
- Establishing shots (quick, efficient)

**AI Video Generation Prompts:**
```
Generate video shot:

Scene: [Context from script]
Shot type: [Close-up, medium, wide]
Subjects: [Character descriptions]
Action: [What's happening]
Emotion: [Mood to convey]
Lighting: [Day/night, mood lighting]
Aspect ratio: 9:16 (vertical)
Style: Cinematic, high-quality, dramatic lighting
Duration: 5-10 seconds

Consistency requirements:
- Character appearance: [Specific details]
- Location: [Environment details]
- Color palette: [Mood colors]
```

**Visual Quality Standards:**
- Resolution: Minimum 1080x1920 (vertical)
- Frame rate: 24 fps (cinematic) or 30 fps
- No visual artifacts
- Consistent character appearance
- Proper lighting
- Sharp focus on key subjects

### Phase 4: Voice Generation

**Character Voice Profiles:**
```
Character: [Name]
Age: [Range]
Gender: [M/F/NB]
Personality: [Traits]
Voice characteristics:
  - Pitch: [Low, medium, high]
  - Tone: [Warm, cold, energetic, calm]
  - Accent: [If any]
  - Speaking style: [Fast, slow, measured]
  - Emotional range: [Demonstrated emotions]
```

**Voice Generation Prompts:**
```
Generate speech for:

Character: [Name with voice profile]
Emotion: [Current emotional state]
Context: [Scene context]
Dialogue: "[Exact text]"

Parameters:
- Emotional intensity: [1-10]
- Speaking pace: [Slow, normal, fast]
- Emphasis: [Specific words to emphasize]
- Pauses: [Where to insert natural pauses]
```

**Audio Quality Standards:**
- Clarity: No distortion
- Volume: Normalized across episodes
- Background: Subtle ambient sound
- Music: Non-intrusive, mood-appropriate
- Sync: Perfect lip-sync with video

### Phase 5: Post-Production

**Assembly:**
1. Combine video shots (5-8 per episode)
2. Add transitions (quick cuts, fades)
3. Layer voice-over
4. Add background music
5. Add sound effects
6. Color grading (consistent look)
7. Add subtitles (auto-generated, reviewed)

**Music Selection:**
- Mood-appropriate
- Royalty-free or licensed
- Subtle (doesn't overpower dialogue)
- Consistent theme per movie
- Volume ducking during dialogue

**Subtitle Standards:**
- Always included
- Accurate to dialogue
- Readable font (size, color, contrast)
- Positioned safely (not cut off)
- Timed perfectly with speech

### Phase 6: Quality Assurance

**Automated Checks:**
- Video resolution: ✓ 1080x1920 or 2160x3840
- Duration: ✓ 58-62 seconds
- Audio sync: ✓ Within 50ms
- Subtitle timing: ✓ Matches audio
- File size: ✓ Optimized for streaming
- No visual artifacts: ✓ Checked

**Human Review Checklist:**
- [ ] Story coherence with previous episodes
- [ ] Character consistency (appearance, voice, personality)
- [ ] Emotional impact (does it land?)
- [ ] Cliffhanger effectiveness
- [ ] Video quality (lighting, framing, focus)
- [ ] Audio quality (clarity, levels, sync)
- [ ] Subtitle accuracy
- [ ] Appropriate content rating
- [ ] No offensive or problematic content

**Rating System:**
```
Overall Quality Score: 1-10

- Story (1-10): Coherence, engagement
- Visual (1-10): Quality, consistency
- Audio (1-10): Clarity, performance
- Pacing (1-10): Rhythm, flow
- Emotion (1-10): Impact, authenticity

Minimum acceptable: 7/10 average
Regenerate if below threshold
```

## Content Standards & Restrictions

### Appropriate Content

✅ **Allowed:**
- Mature themes (betrayal, loss, conflict)
- Romance and intimacy (within guidelines)
- Suspense and tension
- Emotional intensity
- Realistic conflicts
- Complex moral situations
- Violence (in context, not gratuitous)

### Restricted Content

⚠️ **Requires Careful Handling:**
- Sexual content (implied, not explicit)
- Violence (story-relevant, not glorified)
- Mental health topics (respectful portrayal)
- Substance use (realistic, not promotional)
- Death and grief (handled sensitively)

❌ **Prohibited:**
- Explicit sexual content
- Gratuitous violence or gore
- Hate speech or discrimination
- Self-harm promotion
- Illegal activity glorification
- Child endangerment
- Animal cruelty
- Non-consensual acts
- Exploitative content

### Content Ratings

**General (G):**
- Suitable for all audiences
- Minimal conflict
- Light romance
- No mature themes

**Teen (T):**
- Suitable for 13+
- Moderate conflict
- Romance with kissing
- Mild violence (no blood)
- Emotional intensity

**Mature (M):**
- Suitable for 18+
- Complex adult themes
- Intimate romance (implied)
- Violence (contextual)
- Strong emotional content
- Dark themes

**Default Rating:** Mature (M) - our target audience is 18-35

## Pacing & Story Structure

### Three-Act Structure (for 100-episode movie)

**Act 1: Setup (Episodes 1-25)**
- Introduce characters
- Establish world and rules
- Present central conflict
- Build character relationships
- First major plot point (episode 25)

**Act 2: Confrontation (Episodes 26-75)**
- Escalating conflict
- Character development
- Subplots
- Midpoint twist (episode 50)
- Rising tension
- Second major plot point (episode 75)

**Act 3: Resolution (Episodes 76-100)**
- Climax (episodes 85-95)
- Character transformation
- Resolve main plot
- Resolve subplots
- Satisfying conclusion
- Emotional payoff (episode 100)

### Pacing Guidelines

**Every 10 episodes:**
- Major revelation or plot advancement
- Character development moment
- Emotional high or low point

**Every 25 episodes:**
- Act break
- Major plot twist
- Shift in story direction

**Cliffhanger Types (Rotate):**
- Revelation (truth revealed)
- Danger (physical or emotional)
- Decision (character choice)
- Surprise (unexpected event)
- Betrayal (relationship shift)

## Dialogue Guidelines

### Natural Speech

**DO:**
- Use contractions ("I'm" not "I am")
- Include interruptions and pauses
- Vary sentence length
- Character-specific speech patterns
- Subtext (what's not said)

**DON'T:**
- Over-explain (no "As you know, Bob...")
- Use overly formal language (unless character-appropriate)
- Info dumps
- On-the-nose dialogue
- Identical voices for all characters

### Vertical Format Considerations

- Less dialogue per episode (visual focus)
- Clear enunciation
- Expressive delivery
- Close-ups make micro-expressions crucial
- Text on screen can supplement dialogue
