# DramaSnap - AI-Generated Short Drama Streaming Platform

## Project Overview
DramaSnap is a mobile streaming platform for AI-generated short drama content. 60-second vertical episodes, 100 episodes per movie.

## Tech Stack
- **Mobile**: React Native
- **Backend**: Node.js / Python (FastAPI)
- **AI Engine**: GPT-4 (scripts), Runway/Pika (video), ElevenLabs (voice)
- **Database**: PostgreSQL + Redis
